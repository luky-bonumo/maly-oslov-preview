# Malý Oslov – pracovní náhled návrhu homepage

Pracovní návrh nového webu, slouží jen k připomínkování. Není to oficiální web Malého Oslova, ten je na [malyoslov.cz](https://malyoslov.cz). Ceny a texty jsou orientační.

- `index.html` – verze A
- `verze-2.html` – verze 2 (Playfair Display + Jost)
- `verze-3.html` – verze 2 s písmy Bricolage Grotesque + Hanken Grotesk
- `verze-4.html` – verze 2 s písmy Syne + Manrope
- `verze-5.html` – verze 2 s písmy Instrument Serif + Instrument Sans
